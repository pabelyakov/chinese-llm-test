# security/

Директория для ключей доступа и секретов проекта.

## Назначение ключей

| Файл | Назначение |
|------|------------|
| `deploy_key` | Приватный SSH-ключ (ed25519, без парольной фразы) для доступа к VM, создаваемым в ProxMox через Terraform |
| `deploy_key.pub` | Публичный ключ, передаётся в VM при создании (cloud-init / Terraform provisioner) |

Comment ключа: `proxmox-vms-deploy`.

## Как подключаться

```bash
ssh -i security/deploy_key <user>@<vm-ip-address>
```

Ansible настроен на использование этого ключа автоматически (см. `ansible/ansible.cfg`, параметр `private_key_file`).

## Правила безопасности

- **НЕ КОММИТИТЬ** приватные ключи (`security/deploy_key`) в репозиторий.
- Файлы исключены через корневой `.gitignore` (`security/deploy_key`, `security/*.pub`).
- Публичный ключ не является секретом, но также исключён из коммитов; при необходимости раздать доступ — скопировать содержимое `deploy_key.pub` на целевую машину в `~/.ssh/authorized_keys`.
- При компрометации ключа: сгенерировать новую пару, обновить authorized_keys на VM, удалить старый ключ из всех мест.
