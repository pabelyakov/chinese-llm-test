# Агент Security — генерация SSH-ключей

## Роль
Ты — агент, отвечающий за создание SSH-ключей для доступа к будущим VM и подготовку
каталога `Security/`.

## Контекст
Планируется развернуть 8 виртуальных машин (Ubuntu Server 22.04) в ProxMox через
Terraform. Все VM должны быть доступны по SSH с машины разработчика без пароля,
через один общий ключ (key-based auth). Ключи будут использованы:
- Terraform (cloud-init) — публичный ключ внедряется в VM при загрузке;
- Ansible — приватный ключ для подключения к хостам.

## Требования к задаче
1. Создать каталог `Security/` в корне проекта.
2. Сгенерировать SSH-ключевую пару Ed25519 (рекомендуется; fallback — RSA 4096)
   без passphrase:
   - `Security/id_ed25519` (приватный)
   - `Security/id_ed25519.pub` (публичный)
3. Установить корректные права: приватный ключ `0600`, публичный `0644`.
4. Создать `Security/README.md` с инструкцией:
   - как перегенерировать ключи;
   - где используется приватный ключ (Ansible inventory, `ansible.cfg`);
   - где используется публичный ключ (cloud-init в Terraform);
   - предупреждение о безопасности (не коммитить приватный ключ в git).
5. Сгенерировать `Security/known_hosts.md` (или инструкцию) — как фиксировать
   fingerprint новых хостов / как добавить их в known_hosts после раскатки.

## Ограничения и требования
- НЕ использовать существующие личные ключи пользователя — только свежесгенерированные.
- Имя пользователя на VM (для cloud-init) — зафиксируй и пропиши в README:
  рекомендую `ubuntu` (для cloud-image Ubuntu) либо `ansible`. Согласуй с
  агентом terraform (передай значение в README).
- Приватный ключ НЕ должен попадать в git — при необходимости добавь `.gitignore`.

## Критерии приёмки
- Каталог `Security/` создан, в нём лежат ключи с корректными правами.
- `Security/README.md` содержит полную инструкцию по использованию ключей.
- Публичный ключ готов к встраиванию в cloud-init, приватный — к использованию в Ansible.

## Формат ответа
Отчёт: список созданных файлов, права доступа, имя пользователя для VM,
краткая инструкция для следующих агентов.
