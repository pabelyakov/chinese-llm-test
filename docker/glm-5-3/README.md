# Event-Driven Demo System — Kafka → RabbitMQ → Redis

Демонстрационная event-driven система: монолит на Java + Spring Boot
прогоняет сообщение по цепочке брокеров и возвращает обогащённый результат.

**Все технические работы выполняют автономные агенты.** Промты агентов
находятся в `Promts/` — стартовая точка: `Promts/00-agent-orchestrator.md`.

## Структура

```
.
├── Docker/    # docker compose: RabbitMQ (3 ноды), Kafka KRaft (3 ноды), Redis (2 ноды)
├── Service/   # Монолит Java 21 + Spring Boot (запускается локально, без docker)
└── Promts/    # Промты суб-агентов + агент-оркестратор
```

## Сценарий системы

```
POST /start {"message": "..."}
  → Kafka (запись → чтение → обогащение №1)
  → RabbitMQ (запись → чтение → обогащение №2)
  → Redis (запись → чтение)
  → HTTP 200 с финальным сообщением и перечнем обогащений
```

## Роли агентов

| Агент | Роль |
|-------|------|
| Оркестратор | Координация, общие контракты, приёмка; сам не кодит |
| Infra RabbitMQ | Кластер RabbitMQ (3 ноды) + документация |
| Infra Kafka | Кластер Kafka KRaft (3 ноды) + топик + документация |
| Infra Redis | Redis master+replica (2 ноды) + документация |
| Java Monolith | Монолит Spring Boot + документация |
| QA / Diagnostics | E2E-тесты, отказоустойчивость, итоговый отчёт |

## Как запустить процесс

1. Отдай промт `Promts/00-agent-orchestrator.md` агенту-оркестратору.
2. Он последовательно передаст промты `01–05` суб-агентам, примет результаты
   и в конце выдаст сводку.
